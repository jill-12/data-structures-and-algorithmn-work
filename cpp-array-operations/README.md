# C++ Array Operations

This repository contains two forms of the examples:

- `examples/`: separate, independent programs—one file for each array operation.
- `src/array_operations.cpp`: a menu-driven program combining all operations.

## Separate examples

Each file in `examples/` can be compiled and run independently:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic examples/insert.cpp -o insert
./insert
```

The same pattern works for `delete`, `traverse`, `display`, `search`, `update`, `statistics`, `reverse`, and `sort`.

## Included operations

- Insertion
- Deletion
- Traversal
- Display
- Searching
- Updating
- Statistics: minimum, maximum, sum, and average
- Reversing
- Sorting
