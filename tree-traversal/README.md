# Tree Traversal Demo

This folder contains a simple C++ program that demonstrates the main tree traversal techniques used in data structures and algorithms.

## Topic
- Data Structures and Algorithms (DSA) — Tree Traversal

## What the program shows
- Pre-order traversal
- In-order traversal
- Post-order traversal
- Level-order traversal

## File
- `tree_traversal.cpp`

## Sample tree used
The program builds a binary tree with these values:

`50, 30, 20, 40, 70, 60, 80`

## Traversal outputs
The program prints each traversal in order so you can compare how the same tree is visited in different ways.

## Run it
```bash
g++ -std=c++17 "tree_traversal.cpp" -o tree_traversal
./tree_traversal
```
